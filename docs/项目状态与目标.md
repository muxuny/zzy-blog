# 项目状态与目标

这份文档记录博客项目的当前阶段、已完成功能、下一步目标和已排期功能。每次功能方向变动、功能完成或新增/删减时，需要同步更新这份文档。

## 项目定位

个人博客系统，包含公开阅读、创作中心和后台管理，目标是提供清晰、克制、内容优先的阅读和写作体验。

## 已完成功能

### 前端视觉系统

- 内容工作台视觉系统（主题变量、Element Plus 覆盖、全局样式）
- 亮色/暗色主题切换
- 响应式布局（桌面端、平板端、手机端）

### 公开阅读面

- 首页：搜索框（关键词按标题和摘要搜索）、话题导航（标签筛选按钮，点击后在首页内直接过滤）、最近更新（从当前文章列表取第一篇）、文章列表（同一位置根据筛选条件显示不同内容）、状态条、页脚
- 文章详情页：封面图、字数统计、预计阅读时间、目录高亮、悬浮回顶、上一篇/下一篇、相关文章推荐
- 文章收藏：文章详情页支持收藏和取消收藏；未登录收藏意图在登录后续接并返回原文章；“我的收藏”支持关键词搜索、标签筛选和分页，可公开文章支持整卡进入详情且卡内信息不单独高亮；不可用文章保留收藏时标题快照并显示统一不可用提示
- 我的阅读：登录用户从用户菜单进入概览，继续最近一篇可用文章，查看最近历史与收藏，并跳转公开首页发现更多内容
- 阅读历史：登录用户成功打开公开文章后记录首次阅读时间、最近阅读时间和阅读次数；完整历史按时间分组，支持分页、单条删除和清空
- 阅读位置与进度：登录用户阅读文章时保存滚动位置、阅读进度和当前目录标题；再次进入文章时通过可关闭弹窗提示继续阅读；“我的阅读”和“阅读历史”展示阅读进度；文章详情页提供固定在视口右下角的清晰白底图标化阅读工具条，支持阅读中返回和回顶
- 不可公开历史：保留最近阅读时的标题快照，记录置灰且禁止访问并显示统一提示；“上次阅读”自动跳过不可用文章
- 标签文章列表页（/tag/:name）：独立页面和路由已保留，可展示指定标签下的公开文章；当前首页话题按钮在首页内筛选，不作为标签页显性入口；文章卡片标签已有 hover/focus 反馈
- 登录页、注册页

### 创作中心

- 我的文章列表：状态筛选（草稿/待审核/已发布/已驳回）、分组筛选、可见性筛选（公开/仅自己可见）
- 我的文章预览页：从“我的文章”列表标题进入，任何状态的文章都进入创作者侧预览；预览页支持目录导航，并提供直接进入编辑页的按钮；公开查看、分组、删除等动作保留在操作列
- 写文章/编辑文章：标题、摘要、封面图、标签选择、分组选择、可见性设置、Markdown 编辑器；编辑器标题下拉会随光标所在段落同步，代码块后会保留可继续输入的段落落点
- 文章状态流转：草稿或已驳回文章可提交为待审核，待审核文章可撤回为草稿，也可由管理员审核为已发布或已驳回；已发布文章编辑后会重新进入待审核
- 文章分组管理：创建、重命名、删除分组，调整文章分组

### 后台管理

- 后台管理视觉：后台壳、侧栏、顶部栏、仪表盘、文章管理、资源管理、用户管理、个人资料和后台文章编辑页已同步为后台管理视觉原型风格
- 仪表盘：文章状态分布（草稿/待审核/已发布/已驳回）、审核队列（待审核文章、待审核用户）、内容热度、阅读活跃、收藏反馈、资源健康
- 文章管理：全站文章列表、按状态筛选、按可见性筛选、关键词搜索、审核通过/驳回（需填写驳回原因）、编辑、删除
- 资源管理：合并原标签管理和图片管理，支持创建/删除标签、上传/删除图片
- 用户管理：用户列表、审核通过、禁用
- 个人资料：查看用户信息

## 下一阶段候选方向

- 轻量互动能力：优先讨论点赞、喜欢、读后反馈等轻量读者反馈能力，避免直接进入评论审核和运营管理的复杂边界。

- 文件名尽量使用中文，尤其是文档和说明类文件
