# 视觉体验个性化优化设计

## 背景

博客当前基础能力已经比较完整：公开首页与文章详情承担内容发现和阅读，`/reading` 与 `/reading/history` 承担读者个人阅读延续，创作中心承担文章管理、预览、编辑、分组和状态流转。登录用户阅读位置与进度已经完成，并通过真实数据库和页面验收。

下一阶段暂不优先做游客本地阅读历史、热门排行、阅读趋势、评论或点赞。当前博客更偏私人范围使用，体验提升的重点先放在前端视觉个性、阅读触感和轻量互动上。

本轮设计方向为“现代私人知识空间”：保留清晰、克制、内容优先的基调，但让页面更有识别度和可选择的个性。视觉表达避免直接套用笔记纸、书签、胶带、手账等具象书房元素，改用配色、层级、动效和信息组织来形成气质。

## 目标

- 提升公开首页、文章详情、我的阅读、创作空间的整体视觉一致性和个性。
- 提供固定主题包，支持浅色、深色和跟随系统，用户可以按偏好切换。
- 增加不影响功能流程的轻量互动反馈，让页面有动态触感，但不喧宾夺主。
- 保持现有路由、接口、权限和业务流程不变，优先作为纯前端优化落地。
- 保证移动端、键盘可访问性、减少动态效果偏好下仍可正常使用。

## 非目标

- 不新增后端接口、数据库表或数据库字段。
- 不做用户偏好跨设备同步，本期主题选择只保存在浏览器本地。
- 不实现游客本地阅读历史。
- 不实现热门文章、阅读趋势、评论、点赞。
- 不重做后台管理的复杂页面结构；后台仅接入基础主题变量，深度重构后置。
- 不在公开首页文章卡片增加“已读”标签。

## 范围

### 本期重点页面

- 公开首页：搜索、标签筛选、文章列表、内容信号区、继续阅读轻入口。
- 文章详情：正文阅读、目录状态、阅读进度、继续阅读弹窗、收藏、阅读工具条。
- 我的阅读：阅读概览、继续上次阅读、最近历史、最近收藏。
- 创作空间：我的文章列表、筛选、分组、状态标签、创作者预览入口。

### 后台管理

后台管理保持当前信息密度和工作台属性。本期只要求颜色变量、基础按钮和表面样式不与全站主题冲突，不做仪表盘、文章审核、用户管理等页面的专项视觉重构。

## 视觉基调

整体风格是现代、清爽、私密但不复古。页面应像一个被打磨过的个人知识空间，而不是实体书桌或手账页面。

设计特征：

- 使用低饱和复合色，不使用大面积单一紫蓝、纯黑霓虹、纸张泛黄或强烈渐变。
- 卡片半径保持克制，默认不超过 8px。
- 页面结构偏信息索引和工作台，不做营销式大 hero。
- 装饰减少，个性主要来自排版、分隔线、主题色、微交互和内容组织。
- 首页“本周阅读信号”改名为“本周内容信号”或“最近内容节奏”，避免误解成阅读量排行。

## 主题切换设计

### 主题包

主题采用固定主题包，不提供任意调色，避免用户配置破坏整体质感。

第一期提供三套主题包：

- 松针绿：默认主题，清爽克制，延续当前原型色彩。
- 雾蓝灰：更冷静，适合长时间阅读。
- 暖铜绿：更有温度，适合创作空间和夜间写作。

每套主题包都包含浅色和深色 token。实际可组合为 6 种视觉状态。

### 明暗模式

提供三种模式：

- 浅色：固定使用当前主题包的浅色 token。
- 深色：固定使用当前主题包的深色 token。
- 跟随系统：根据 `prefers-color-scheme` 自动切换浅色或深色。

### 保存策略

本期使用 `localStorage` 保存：

- `palette`：主题包标识。
- `mode`：浅色、深色或跟随系统。

未选择时默认使用“松针绿 + 浅色”。如果浏览器禁止本地存储，页面仍按默认主题工作，不弹错误提示。

后续如需要跨设备同步，再另行设计用户偏好接口和数据库字段。

### 入口位置

推荐在顶部用户相关操作区增加“外观”入口。桌面端展示为文本或图标加文字按钮，移动端可放入用户菜单或更多菜单。入口不应压缩主要导航，也不应覆盖阅读正文。

## 页面设计

### 公开首页

首页仍负责内容发现，不承担个人阅读历史展示。

首页结构建议：

- 顶部区域展示站点名称、当前内容方向和“本周内容信号”。
- 搜索和标签筛选保持现有逻辑，筛选后在同一区域更新文章列表。
- 文章卡片保留标题、摘要、标签、发布时间、预计阅读时间等核心信息。
- 继续阅读只作为轻入口，不扩展为完整“我的阅读”面板。

“本周内容信号”展示内容：

- 最近活跃主题：从最近发布或更新文章的标签、分类中聚合。
- 最近更新文章：展示一篇最近发布或更新的文章标题。
- 7 天内容节奏条：表示公开文章发布或更新分布，不表示阅读量。
- 轻量摘要：例如“本周更新 2 篇，集中在前端体验、创作流程”。
- 空状态：本周无公开更新时展示“本周暂无新更新，可从专题继续阅读”。

### 文章详情

文章详情页继续以正文阅读为主。

优化点：

- 顶部阅读进度线随滚动更新。
- 目录当前项使用轻微滑动或吸附反馈，不只依赖颜色变化。
- 继续阅读弹窗保留现有行为，但视觉跟随新主题 token。
- 右下角阅读工具条保持清晰可见，风格接近原回顶按钮，不与正文、目录或弹窗粘连。
- 收藏、返回、回顶等操作提供短反馈，不增加确认步骤。

### 我的阅读

我的阅读定位为“阅读续接台”，用于延续登录用户自己的阅读轨迹。

优化点：

- 继续上次阅读区域更明确，显示标题、进度、最近阅读时间和入口。
- 最近历史和最近收藏保留现有数据边界，不新增游客历史。
- 不可公开文章继续置灰、禁止访问，并保留统一提示。
- 点击历史项或收藏项时提供轻微聚焦反馈。

### 创作空间

创作空间定位为“创作控制台”，重点是效率和状态清晰。

优化点：

- 文章列表行 hover 时显示左侧聚焦线或轻微抬升。
- 状态标签按主题 token 调整颜色，草稿、待审核、已发布、已驳回仍清晰区分。
- 分组筛选和状态筛选使用统一控件风格。
- 创作者预览入口保持现有逻辑，不把公开查看、编辑、删除等动作混在标题入口里。

## 动效与趣味交互

本期动效遵循“短、轻、可关闭感弱”的原则，只在用户动作附近出现。

可落地点：

- 文章卡片 hover：边线、左侧焦点线、局部高光轻微变化。
- 搜索框 focus：底部扫描线或边框反馈。
- 标签筛选：列表项淡入和轻微位移动画。
- 文章详情目录：当前项滑动、章节指示条变化。
- 阅读完成或进度保存：非阻断式小提示。
- 我的阅读继续按钮：进度条给一次短促响应。
- 创作列表：状态筛选和预览切换时轻微过渡。

约束：

- 不做常驻大动画。
- 不做影响阅读的循环特效。
- 支持 `prefers-reduced-motion: reduce`，减少或关闭非必要动画。
- 动效失败不影响功能使用。

## 前端实现边界

后续实现建议优先抽出主题和交互基础能力：

- 主题 token：背景、表面、正文、次级文本、边框、强调色、状态色、阴影、网格或细线颜色。
- 主题应用：通过 `data-palette` 和 `data-theme` 或等价方式控制 CSS 变量。
- 主题持久化：封装本地存储读写，处理异常降级。
- 外观入口：提供主题包和明暗模式选择。
- 动效工具类：复用 hover、focus、列表过渡、非阻断提示样式。

正式实现应沿用现有 Vue 3、Element Plus、路由、接口和状态管理方式，不引入新框架。

## 异常与边界

- 未登录用户可以切换外观，但不显示“我的阅读”入口之外的登录专属数据。
- 本地存储不可用时，使用默认主题，不提示错误。
- 系统主题切换时，仅在“跟随系统”模式下自动改变明暗。
- 移动端主题面板不得遮挡主要操作，打开后可以点击外部或按 Esc 关闭。
- 不可公开文章、收藏、阅读历史、阅读位置恢复等已有业务边界保持不变。
- 老浏览器不支持部分高级 CSS 时，页面应退化为可读、可操作状态。

## 验收标准

- 用户可以在三套固定主题包之间切换，并在浅色、深色、跟随系统之间切换。
- 切换主题后，公开首页、文章详情、我的阅读、创作空间的颜色和基础交互一致。
- 刷新页面后保留上次选择的主题包和明暗模式。
- 首页“本周内容信号”不表现为阅读排行或热门榜。
- 搜索、标签筛选、文章详情阅读、继续阅读、收藏、阅读历史、创作中心文章操作等现有功能不回退。
- 移动端无文字溢出、按钮重叠、面板遮挡关键操作的问题。
- 开启减少动态效果后，页面仍可正常阅读和操作。
