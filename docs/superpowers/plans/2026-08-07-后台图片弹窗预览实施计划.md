# 后台图片弹窗预览 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在后台资源管理图片素材列表中增加弹窗大图预览，让管理员能看清原图、复制图片地址，并可从弹窗删除当前图片。

**Architecture:** 仅修改前端资源管理页，复用已有图片分页列表返回的 `url`、文件名、大小、上传人和创建时间。使用 Element Plus `el-dialog` 承载大图预览，删除继续走已有 `deleteImage` 接口和当前分页刷新逻辑，不新增后端接口、数据库表或字段。

**Tech Stack:** Vue 3 `<script setup>`、Element Plus、Node.js `node:test` 源码契约测试、Vite 构建。

- [ ] **Step 4: Add preview and copy handlers**

After `handleDeleteImage`, add:

```js
function getImageName(image) {
  return image?.originalName || image?.name || '未命名图片'
}

function openImagePreview(image) {
  if (!image?.url) {
    ElMessage.warning('图片地址不可用')
    return
  }
  previewDialog.value = {
    visible: true,
    image,
    loadError: false
  }
}

function closeImagePreview() {
  previewDialog.value = {
    visible: false,
    image: null,
    loadError: false
  }
}

async function copyImageUrl() {
  const url = previewImage.value?.url
  if (!url) {
    ElMessage.warning('图片地址不可用')
    return
  }
  try {
    await navigator.clipboard?.writeText(url)
    ElMessage.success('图片地址已复制')
  } catch (error) {
    ElMessage.error('复制失败')
  }
}

async function handleDeletePreviewImage() {
  await handleDeleteImage(previewImage.value?.id, { closePreview: true })
}
```

- [ ] **Step 5: Let deletion optionally close the dialog**

Replace the existing `handleDeleteImage` function with:

```js
async function handleDeleteImage(id, options = {}) {
  if (!id) return
  await deleteImage(id)
  ElMessage.success('删除成功')
  if (options.closePreview) {
    closeImagePreview()
  }
  imagePage.value = getPageAfterSingleDeletion({
    page: imagePage.value,
    size: imageSize.value,
    total: imageTotal.value
  })
  await loadImages()
}
```
