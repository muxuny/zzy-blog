# 页面文案配置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build admin-configurable page-level `eyebrow`、`title`、`description` for the first 17 functional pages.

**Architecture:** The backend owns persisted overrides in a `page_copy` table and exposes public read plus admin maintenance endpoints. The frontend owns the default copy catalog and always renders defaults first, then merges server data through a Pinia store so page copy failures do not break page rendering.

**Tech Stack:** Spring Boot 2.7, MyBatis-Plus, MySQL incremental SQL, Vue 3, Pinia, Element Plus, Node native tests.
